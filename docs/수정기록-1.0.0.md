# LightCapture v1.0.0 버전 표기

2026-10-30. 사용자가 지정한 v1.0.0으로 프로그램 버전을 통일했다. 정보 보기의 1.0.0, 실행 파일의 FileVersion·ProductVersion, 숫자 버전 1.0.0.0과 매니페스트를 일치시켰다. Windows 파일 속성에서도 버전을 읽을 수 있도록 한국어 리소스 언어와 버전 문자열을 명시했다.

기능과 저장 데이터 형식은 0.1.23과 같다. 기존 캡처·그림판·편집·클립보드·저장·캔버스 확장·목록·반응성 개선을 유지한다. 성능 수치는 [0.1.23 측정 기록](성능-메모리-점검-0.1.23.md)을 그대로 참조하며 이번 버전 표기 변경으로 성능을 다시 측정했다고 주장하지 않는다. 실제 입력·혼합 DPI 등 기존 검증 범위도 유지한다.

파일 속성의 FileVersion·ProductVersion 1.0.0 및 숫자 버전 1.0.0.0과 x64 대상을 확인했다. 핵심 49개·복사 형식 11개·사각형 선택 74개·그림판 23개·캔버스/붙여넣기 50개 및 기존 텍스트·목록 자체 회귀를 통과했다. 실행 파일·ZIP·바탕화면·Git 저장소에 반영한다. 검증 근거는 `verification/v1.0.0/`에 보관한다.
