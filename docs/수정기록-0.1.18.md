# LightCapture 0.1.18 선택 영역 크기 조절

2026-10-30. 사각형으로 선택한 영역의 네 테두리와 네 모서리를 드래그해 사진과 주석의 크기를 함께 조절한다. 안쪽은 기존 이동 동작을 유지한다. 방향별 커서와 흰색 조절점 8개를 표시하며 화면 확대·축소 시 히트 범위의 화면상 크기를 유지한다.

축소 시 비는 원래 자리는 흰색으로 채우고, 크기가 바뀐 결과가 겹치는 곳은 덮어쓴다. 고품질 보간을 사용한다. 현재 보이는 사진·자르기 경계 안에서 최소 1×1픽셀까지 조절하며 가로·세로 비율은 자유롭게 바뀐다. Ctrl+Z 한 번은 마지막 조절을 복원하고 Esc는 진행 중인 조절을 취소한다. 선택 부분 복사와 전체 편집 이미지 저장에 결과를 반영한다.

기존 한 점 이동 명령을 읽을 수 있다. 크기가 바뀐 명령은 두 번째 점에 도착 영역의 오른쪽 아래 좌표를 기록하며 읽을 때 원본·도착 경계를 검사한다. 크기 조절한 내부 기록을 다시 열 때는 0.1.18 이상을 사용한다.

검증 결과는 `verification/v0.1.18/`에 보관한다. 사용자 화면 수집이나 실제 입력·클립보드 조작은 자동화하지 않는다.

핵심 회귀 49개, 기본 클립보드 형식 11개, 사각형 선택·이동·크기 조절 74개와 기존 목록·편집 회귀를 통과했다. 8방향 크기 조절의 커서·선택 범위·편집 기록 한 번 적용·주석과 픽셀 반영·Ctrl+Z를 검사했다. 축소 후 이동, 확대, 1×1 최소 크기, 사진·자르기 경계, Esc 취소, 무변화 드래그, 확대율별 히트 범위, 저장·복사·메타데이터 재열기를 확인했다. 기본 크기와 720×480 자체 컨트롤 렌더를 확인했으며 Computer Use·실제 화면 캡처·외부 앱 입력·시스템 클립보드 변경은 수행하지 않았다.
