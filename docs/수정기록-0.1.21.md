# LightCapture 0.1.21 캔버스 확장과 이미지 붙여넣기

2026-10-30. 캔버스 오른쪽·아래쪽 가장자리의 hover·드래그로 흰색 편집 범위를 확장한다. 상시 크기 조절 사각형 대신 해당 가장자리 강조·작은 점·방향 커서를 사용한다. 원본과 기존 편집 픽셀을 늘리지 않고 새 여백을 추가한다. 드래그 중 Esc는 취소하며 확정 후 Ctrl+Z로 크기와 편집 범위를 되돌린다. 안쪽 드래그는 축소·잘라내기로 처리하지 않는다.

Ctrl+V·편집 메뉴로 클립보드의 PNG·DIBV5·DIB·비트맵 이미지를 읽어 현재 문서에 개체로 붙인다. 선택 도구로 이동·크기 조절이 가능하고 큰 이미지는 한 번의 붙여넣기 명령으로 캔버스도 확장한다. 텍스트 입력 중 Ctrl+V는 네이티브 글자 붙여넣기를 유지한다. 빈 목록이면 새 이미지 문서를 추가한다.

확장·붙여넣기 기록은 v3 메타데이터로 보관하며 기존 v1·v2도 읽는다. 이미지 바이트를 공유하고 파일에는 이전 명령 참조를 사용해 이동·크기 조절마다 PNG를 중복 저장하지 않는다. 클립보드 데이터의 크기·헤더·픽셀 경계를 검사하고 고전 DIB의 불명확한 알파는 불투명으로 처리한다. 0.1.21 이상에서 새 기록을 다시 열어야 한다.

검증 결과는 `verification/v0.1.21/`에 보관한다. 사용자 클립보드나 실제 화면은 시험에서 읽거나 바꾸지 않는다.

캔버스·붙여넣기 검사 30개, 기존 그림판·굵기 막대 23개, 핵심 회귀 49개, 기본 복사 형식 11개, 선택·이동·크기 조절 74개 및 기존 텍스트·목록 회귀를 통과했다. 확장 후 새 공간 그리기, Undo·Esc·안쪽 드래그·자르기 시작점·잘라 숨긴 원본 대신 흰색 여백, 저장·재열기를 확인했다. PNG의 투명 픽셀·DIB·DIBV5 디코딩·잘린 입력 거부, 붙여넣기 개체 이동·크기·저장·Undo·자동 확장과 빈 문서 붙여넣기를 검사했다. 파일 내 이미지 데이터 공유 참조와 드래그 중 버퍼 재사용·해제도 확인했다. 기본/720×480 자체 컨트롤 렌더를 확인했으며 실제 외부 앱에서 복사하거나 사용자 클립보드를 읽고 쓰는 시험은 수행하지 않았다.
