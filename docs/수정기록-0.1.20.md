# LightCapture 0.1.20 흰색 그림판 캔버스와 세로 펜 굵기 조절

2026-10-30. 그림판 버튼·파일 메뉴·Ctrl+N으로 1280×720 불투명 흰색 문서를 최근 목록에 추가한다. 바로 새 문서를 표시하고 펜을 선택한다. 기존 캡처·그림·체크 상태와 입력 중 텍스트를 보존하고 기존 보관 한도를 따른다. 일반 문서와 같은 편집·Undo·저장·복사·재열기 기능을 사용한다. 추가적인 상주 전체 화면 버퍼는 만들지 않는다.

펜 전용 왼쪽 세로 트랙바를 추가했다. 위쪽은 굵게·아래쪽은 얇게 조절하며 범위는 기존 설정 호환 범위인 1~80px이다. 휠은 1px씩 조절하며 현재 값도 표시한다. 다른 도구는 막대가 숨겨지고 편집 공간이 확장된다. 새로 그리는 선부터 반영하고 기존 주석은 바꾸지 않는다. 상단 굵기 버튼과 맞춤 버튼·메뉴·명령을 제거했다. 문서를 선택할 때의 초기 배율 계산과 Ctrl+휠은 유지한다.

검증 결과는 `verification/v0.1.20/`에 보관한다. Computer Use·실제 화면 캡처·외부 앱 입력·시스템 클립보드 변경은 수행하지 않는다.

그림판·펜 막대 검사 23개, 핵심 회귀 49개, 기본 복사 형식 11개, 선택·이동·크기 조절 74개 및 기존 텍스트·목록 회귀를 통과했다. 새 문서의 전체 픽셀이 불투명 흰색인지, 목록 맨 위 추가·현재 편집 전환·기존 편집과 체크 보존·입력 중 텍스트 확정·저장·복사·재열기를 확인했다. 굵기 막대 값과 실제 펜 폭·휠 양방향·상하한·펜 전용 표시·최소 창 배치 및 기존 맞춤 동작 제거를 검사했다. 자체 숨긴 앱의 핸들러에 직접 메시지를 전달하며 외부 마우스나 키 입력을 보내지 않았다. 기본 크기와 720×480 자체 컨트롤 렌더를 확인했다.
