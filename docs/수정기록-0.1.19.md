# LightCapture 0.1.19 텍스트 입력 상자 이동·크기 조절과 잔상 수정

2026-10-30. 입력 중 텍스트 상자의 테두리를 드래그해 위치를 옮기고, 모서리·각 변 중앙의 조절점 8개로 너비·높이를 바꾼다. 글자 크기·입력 내용·선택 범위와 같은 EDIT 창을 유지하며 사진 범위 안에서 조절한다. 드래그 중 Esc는 드래그만 취소한다. 기존 텍스트 재편집에서도 적용하고 확정 시 기존 한 번의 편집 명령으로 저장한다.

투명 배경 위 네이티브 EDIT의 부분 갱신에 의존하던 입력 표시를 바꿨다. 입력창의 사진 배경을 임시 비트맵에 먼저 채우고 네이티브 글자·선택 표시를 그린 뒤 한 번에 복사한다. 입력 변경·스크롤 시 전체 입력창을 무효화하고 캔버스에 WS_CLIPCHILDREN을 적용해 자식 입력창 위로 캔버스가 그려지는 것을 막는다. 한글 입력은 기존 Windows EDIT와 IME를 유지한다.

검증 결과는 `verification/v0.1.19/`에 보관한다. Computer Use·사용자 화면 수집·실제 키 입력·시스템 클립보드 변경은 수행하지 않는다.

창을 작게 바꿨을 때 입력 중인 상자가 화면 밖으로 사라지지 않도록 사진 표시 위치를 조정한다. 상자와 글자의 실제 이미지 좌표는 유지한다.
