## 0.1.14 Fluent Light 적용 — 2026-10-26

선택된 1번 시안의 밝은 도구 모음·파란 저장 버튼·가로 목록을 적용했다. 핵심 회귀 **49개**, 기본 클립보드 형식 **11개**, 사각형 선택 **21개**와 기존 자체 UI 회귀를 통과했다. 자체 렌더에서 썸네일이 실제 목록 좌표에 그려지는지, 저장 버튼의 파란 채움과 흰 글자가 함께 표시되는지 픽셀 검사했다. 기본 크기 및 720×480 렌더를 확인했으며 작은 창의 일부 긴 정보는 말줄임한다. 실행 파일 PE machine은 **0x8664 AMD64**로 확인했다. 사용자 화면·Computer Use·실제 마우스 입력은 사용하지 않았으며 혼합 DPI와 실제 입력 조작 검증은 남아 있다. [0.1.14 근거](../verification/v0.1.14/)와 [수정 기록](수정기록-0.1.14.md)을 참고한다.

## 0.1.12 추가 검증 — 2026-10-25

핵심 회귀 49개, 복사 형식·픽셀 시험 11개 및 자체 숨긴 앱의 기존 회귀를 통과했다. [0.1.12 근거](../verification/v0.1.12/)와 [수정 기록](수정기록-0.1.12.md)을 참고한다. PNG 디코딩·24비트 DIB·DIBV5의 모든 픽셀을 비교했고 합성 GDI 캡처 버퍼 파괴 후 색상·알파가 유지됨을 확인했다. 실제 별도 클립보드 공간 생성은 Windows 권한 오류로 실패했다. 사용자 클립보드를 쓰는 시험은 명시적 허용이 있을 때만 별도 수행한다. 실제 카카오톡 붙여넣기는 아직 미시험이다.

같은 날 사용자 허용 후 `ClipboardTests.exe --system-clipboard`를 실행해 기본 시험을 포함한 **27개 시험을 통과**했다. 실제 SetClipboardData로 PNG·CF_DIB·CF_DIBV5를 게시하고 클립보드를 닫았다가 다시 열어 GetClipboardData로 읽었다. 모든 픽셀·크기·행 방향이 유지됐으며 Windows가 변환한 CF_BITMAP에서도 원래 색상을 확인했다. 2회 연속 복사·재읽기를 수행했고 현재 클립보드는 작은 합성 시험 이미지로 교체됐다. [실제 클립보드 시험 기록](../verification/v0.1.12/clipboard-native-tests.txt)을 보관한다. 다른 앱 입력·사용자 화면 수집·Computer Use는 수행하지 않았다. 카카오톡 자체 붙여넣기는 이 시험에 포함되지 않는다.

## 0.1.11 기록

2026-10-23 기준으로 현재 배포 실행 파일의 핵심 회귀 시험 49개와 자체 숨긴 컨트롤·합성 이미지 내부 회귀를 통과했습니다. [시험 기록](../verification/v0.1.11/)을 함께 보관합니다. 개인 환경·기기 정보, 사용자 화면, 캡처 데이터와 작업용 임시 파일은 포함하지 않습니다.

Computer Use·사용자 화면 캡처·외부 입력 자동화를 사용하지 않았습니다. 실제 물리 키 입력, Windows 대화상자 조작, 다른 앱 붙여넣기, 실제 창 숨김 잔상, 혼합 DPI·다중 모니터, 실제 스크롤 대상 호환성·대량 작업 성능, 장시간 상주 메모리와 알캡처 직접 비교는 남아 있습니다. 내부 시험 성공을 전체 기능 동등성으로 해석하지 않습니다. 0.1.11에서 메모리·지연을 새로 측정하지 않았습니다.
