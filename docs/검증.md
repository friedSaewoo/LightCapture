# LightCapture 검증 범위

## 0.1.12 추가 검증 — 2026-10-25

핵심 회귀 49개, 복사 형식·픽셀 시험 11개 및 자체 숨긴 앱의 기존 회귀를 통과했다. [0.1.12 근거](../verification/v0.1.12/)와 [수정 기록](수정기록-0.1.12.md)을 참고한다. PNG 디코딩·24비트 DIB·DIBV5의 모든 픽셀을 비교했고 합성 GDI 캡처 버퍼 파괴 후 색상·알파가 유지됨을 확인했다. 실제 별도 클립보드 공간 생성은 Windows 권한 오류로 실패했다. 사용자 클립보드를 쓰는 시험은 명시적 허용이 있을 때만 별도 수행한다. 실제 카카오톡 붙여넣기는 아직 미시험이다.

## 0.1.11 기록

2026-10-23 기준으로 현재 배포 실행 파일의 핵심 회귀 시험 49개와 자체 숨긴 컨트롤·합성 이미지 내부 회귀를 통과했습니다. [시험 기록](../verification/v0.1.11/)을 함께 보관합니다. 개인 환경·기기 정보, 사용자 화면, 캡처 데이터와 작업용 임시 파일은 포함하지 않습니다.

| 항목 | 확인 범위 |
| --- | --- |
| 캡처 시작 준비 | 숨김·합성 연속 확인 판정, 조기 시작·복원 차단, 준비 취소·시간 초과 |
| 캡처 취소 | 자체 숨긴 영역/창/크기 지정·지연·합성 스크롤 상태의 취소, 문서 유지 |
| 편집 | 아이콘·팔레트·인라인 텍스트·실행 취소·저장 전 입력 확정·자체 렌더 |
| 목록 | 사진 클릭 체크 전환, Shift 범위, 활성 사진 유지·변경, 삭제 후 체크 정리 |
| 저장 | 체크 대상 내보내기, 전체 체크 후 저장, 편집 픽셀·충돌 파일 보존·폴더 취소 |
| 체크 삭제 | 체크 없음·취소·실제 파일 잠금 부분 실패·재시도·현재 사진 유지/전환·전체 삭제·재읽기 |
| 복사 | 메뉴 명령과 편집된 DIB 헤더·픽셀 검사. 사용자 클립보드는 변경하지 않음 |
| 폴더 선택 | 실제 Shell COM 객체 옵션·한글 초기 경로 조회. 선택창은 표시하지 않음 |

Computer Use·사용자 화면 캡처·외부 입력 자동화를 사용하지 않았습니다. 실제 물리 키 입력, Windows 대화상자 조작, 다른 앱 붙여넣기, 실제 창 숨김 잔상, 혼합 DPI·다중 모니터, 실제 스크롤 대상 호환성·대량 작업 성능, 장시간 상주 메모리와 알캡처 직접 비교는 남아 있습니다. 내부 시험 성공을 전체 기능 동등성으로 해석하지 않습니다. 0.1.11에서 메모리·지연을 새로 측정하지 않았습니다.
