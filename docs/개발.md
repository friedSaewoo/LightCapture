# LightCapture 개발·빌드

## 요구 환경

- Windows x64, PowerShell
- C++17을 지원하는 w64devkit의 g++, windres, strip
- 현재 배포본은 w64devkit 2.10.1 / GCC 16.2.0으로 빌드

도구체인은 저장소에 포함하지 않습니다. [w64devkit 공식 저장소](https://github.com/skeeto/w64devkit)에서 준비합니다.

## 빌드

저장소 루트에서 다음을 실행합니다.

```powershell
.\build.ps1 -Toolchain 'C:\Tools\w64devkit\bin'
```

또는 `LIGHTCAPTURE_TOOLCHAIN` 환경변수에 bin 경로를 지정하거나 PATH에서 g++.exe를 찾을 수 있게 합니다. 출력은 루트의 LightCapture.exe와 build 폴더의 시험 실행 파일입니다. 저장소의 bin/LightCapture.exe는 0.1.16 배포본이며 새 빌드가 자동으로 덮어쓰지 않습니다. 실행 파일 대상은 AMD64(x64)입니다.

## 시험

```powershell
.\Run-Verification.ps1 -EvidenceDirectory '.\verification\run-local'
```

새 디렉터리를 사용합니다. 핵심 시험·렌더 시험·자체 숨긴 창 내부 회귀·짧은 상주 시험을 실행합니다. 사용자 데스크톱을 캡처하거나 외부 앱에 입력을 주입하지 않습니다. 현재 화면의 실제 캡처 품질·단축키·붙여넣기 확인과 구분해야 합니다.

개별 자체 시험도 빈 전용 데이터 위치에서 실행할 수 있습니다.

```powershell
.\LightCapture.exe --verify --data 'C:\Temp\LightCapture-test-new'
```

## 복사 호환성 시험

`build/ClipboardTests.exe`의 기본 실행은 합성 픽셀로 PNG·24비트 DIB·DIBV5를 만들고 각 형식의 크기·행 방향·색상·투명도 합성 결과를 비교합니다. 실제 화면이나 사용자 클립보드를 읽거나 바꾸지 않습니다. 같은 GDI 픽셀 전달 경로는 메모리 DC를 사용해 검사합니다.

```powershell
.\build\ClipboardTests.exe
```

실제 SetClipboardData/GetClipboardData와 Windows의 CF_BITMAP 호환 변환 시험은 다음 명시적 옵션에서만 수행합니다. `--system-clipboard`는 현재 클립보드를 작은 시험 이미지로 바꾸므로 기존 내용이 필요하면 실행하지 않습니다. `--isolated`는 별도 창 스테이션을 생성하며 Windows 권한상 실패할 수 있습니다. 격리 생성 실패 시 사용자 클립보드로 대신 시험하지 않습니다. 어느 옵션도 외부 앱에 붙여넣거나 키를 주입하지 않습니다.

```powershell
.\build\ClipboardTests.exe --system-clipboard
.\build\ClipboardTests.exe --isolated
```
