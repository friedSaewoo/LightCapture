# LightCapture 0.1.22 네 방향 캔버스 확장과 붙여넣기 여백

2026-10-30. 캔버스 위·왼쪽 가장자리와 모든 모서리의 확장을 추가했다. 마우스를 테두리 바로 바깥에 올렸을 때만 조절 표시·방향 커서가 나타난다. 이미지 안쪽의 영역 선택·펜 입력과 충돌하지 않는다. 위·왼쪽을 늘릴 때 원본을 변형하지 않고 그쪽에 흰색 여백을 추가하며 기존 그림의 화면상 위치를 고정한다. 확장 전 주석의 위치를 변환해 기존 도형·펜·텍스트를 계속 선택·수정할 수 있다. Undo·Esc·저장·재열기도 지원한다.

크거나 여백이 부족한 이미지를 붙일 때 위치를 캔버스 시작점에서 32px 띄우고 오른쪽·아래에도 최소 32px 여백을 더한다. 이미지 크기 조절점과 캔버스 테두리의 겹침을 줄인다. 이 자동 확장과 붙여넣기는 기존처럼 Ctrl+Z 한 번으로 되돌린다. 작은 이미지가 충분한 여백 안에 들어가면 기존처럼 붙이며 캔버스를 늘리지 않는다.

v3 기록에 좌상단 여백 이동 명령을 추가했다. 기존 v1·v2·v3를 읽으며 새 좌상단 확장·여백 기록은 0.1.22 이상에서 다시 연다. 이미지 데이터 공유와 메모리·이미지 크기 제한은 유지한다.

검증 결과는 `verification/v0.1.22/`에 보관한다. 사용자 화면·물리 입력·시스템 클립보드는 시험에서 읽거나 변경하지 않는다.

캔버스·붙여넣기 검사 50개, 기존 그림판·막대 23개, 핵심 회귀 49개, 복사 형식 11개, 사각형 선택·이동·크기 조절 74개와 기존 텍스트·목록 회귀를 통과했다. 새 검사에는 네 변·네 모서리 커서, 위·왼쪽 확장 픽셀·화면 고정·Undo·Esc·기록 재열기, 확장 전 도형·가로 펜 선의 선택·이동과 큰 붙여넣기의 32px 여백·조절점 분리·재열기가 포함된다. 기본 크기와 720×480 자체 렌더를 확인했다.
