# LightCapture 0.1.17 현재 캡처 저장 단축키

2026-10-28. Ctrl+S를 체크한 목록 저장에서 현재 편집 이미지 한 장 저장으로 변경했다. 체크가 없어도 동작하고 다른 사진을 체크했어도 현재 이미지를 저장한다. 파일 이름·위치·형식을 고르는 기존 저장창을 사용한다. 텍스트 입력 중에도 내용을 확정하고 현재 이미지 저장을 실행한다. 목록 상단 저장 버튼과 파일 → 체크한 캡처 저장은 기존 일괄 저장을 유지한다. Ctrl+Shift+S는 기존 다른 이름으로 저장이다.

검증 결과는 `verification/v0.1.17/`에 보관한다. 실제 사용자 입력과 저장 대화상자 조작은 자동화하지 않는다.

핵심 회귀 49개, 기본 클립보드 형식 11개, 영역 선택 21개 및 기존 목록·편집 회귀를 통과했다. 자체 숨긴 앱에서 체크 없음·다른 사진만 체크된 상태의 현재 이미지 저장과 편집 픽셀·크기를 확인했다. 저장 취소 시 마지막 저장 경로 유지와 텍스트 입력 확정 후 저장도 확인했다. 저장 경로 선택은 시험용 함수로 대체했으며 실제 키 입력·사용자 화면 수집·시스템 클립보드 변경은 수행하지 않았다.
