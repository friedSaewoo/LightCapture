# LightCapture 0.1.14 Fluent Light 적용

2026-10-26. 사용자가 선택한 1번 시안의 전체 화면 구성을 적용했다. [디자인 기준](../DESIGN.md)을 함께 보관한다.

## 바뀐 화면

- 흰색 도구 모음, 옅은 청회색 캔버스, 밝은 오른쪽 목록과 파란 저장 버튼을 사용한다. 부드러운 모서리·얇은 구분선을 추가했다.
- 목록은 체크박스 → 가로 썸네일 → 이미지 크기/캡처 시각 → 제거 X로 재배치했다. 체크 항목은 옅은 파랑으로, 현재 편집 항목은 얇은 파란 테두리로 구분한다.
- 상단 삭제/저장은 체크한 항목만 처리하며 체크가 없으면 비활성화한다. 전체 저장은 전체 체크 후 저장으로 유지한다.
- 넓은 창은 캡처·편집 아이콘·20색 팔레트·옵션을 한 줄로 보여주며, 작은 창에서는 그룹별로 줄바꿈한다. 긴 목록 문구는 말줄임한다.
- 마우스 hover·눌림·키보드 포커스를 표시한다. 네이티브 버튼·목록 의미와 기존 키 입력을 유지한다.

## 유지한 기능과 범위

전역 캡처 키, 창 숨김 확인 후 캡처, 영역 선택·이동, Ctrl+Z, 선택 영역/전체 이미지 복사, 인라인 텍스트, 체크 삭제·저장, 탐색기형 폴더 선택, 기존 원본·편집 기록을 유지했다. 시안에 임의로 생성된 실행 취소·다시 실행 버튼은 기존 요청에 맞춰 추가하지 않았다. 새 애니메이션·블러·웹 런타임을 넣지 않았고 정적 색상·도형 중심으로 그린다. Win32는 Windows API 이름이며 실행 파일은 Windows 11 **x64(AMD64)**다.

## 검증

최적화 빌드와 핵심 회귀 49개, 기본 복사 형식 11개, 영역 선택 21개 및 기존 UI 회귀를 통과했다. 썸네일의 실제 행 좌표와 저장 버튼의 파란 채움·흰 글자를 자체 렌더 픽셀로 검사했다. 기본 크기와 720×480에서 자체 컨트롤 렌더를 확인했으며 기본 목록·체크·X·Shift 범위·삭제 실패 처리도 기존 시험을 통과했다. PE 헤더의 machine 값은 0x8664다.

Computer Use·사용자 화면 캡처·실제 마우스 조작·사용자 클립보드 쓰기를 수행하지 않았다. 실제 입력·혼합 DPI·다중 모니터의 외관·장시간 메모리와 반응속도는 새로 측정하지 않았다. 생성 시안의 예시 호수 웹페이지는 프로그램에 포함하지 않는다.
