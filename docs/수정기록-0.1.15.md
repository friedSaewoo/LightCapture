# LightCapture 0.1.15 좁은 목록과 큰 썸네일

2026-10-26. 사용자의 후속 요청으로 캡처 목록을 이미지 중심으로 단순화했다.

- 오른쪽 목록 패널 폭을 0.1.14 대비 약 2/3로 줄인다. 창 크기·배율에 따라 실제 픽셀 수는 달라진다.
- 각 항목에서 해상도·캡처 시간의 표시를 제거한다. 원본 크기·보관 메타데이터 자체는 유지한다.
- 썸네일이 항목의 가로폭을 넓게 사용하도록 바꾸고 이미지 자체에 연한 테두리를 넣는다. 원본 종횡비를 유지하며 높이가 큰 이미지는 축소해 전체를 보여준다.
- 체크박스와 개별 제거 X를 이미지 아래로 옮기고 항목 높이를 조정한다. 삭제/저장·전체 체크·선택 개수는 좁은 헤더 안에 유지한다.
- 사진 클릭 체크 전환, Shift 범위, 전체 체크, 체크 삭제·저장, 복사·편집·영역 선택·캡처 동작은 유지한다.

핵심 회귀·복사 형식·영역 선택 및 기존 목록 시험을 재실행하고, 기본/720×480에서 폭 비율·헤더 겹침·썸네일 확대·연한 테두리·체크/제거 적중 영역을 확인한다. 실제 결과는 `verification/v0.1.15/`에 기록한다. 자체 렌더·합성 이미지를 사용하며 Computer Use·사용자 화면 캡처·시스템 클립보드 조작은 하지 않는다. 실제 마우스·혼합 DPI·긴 캡처 목록 스크롤 성능은 별도 확인이 남는다.
