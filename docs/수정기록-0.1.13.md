# LightCapture 0.1.13 사각형 선택·이동

2026-10-26. 그림판의 사각형 선택처럼 사진 일부를 선택해 떼어 옮기는 도구를 추가했다. 맨 왼쪽 점선 사각형 아이콘으로 실행하며 기존 개체 선택 화살표는 유지한다.

## 동작

- 사진 위 사각형 드래그는 픽셀 선택만 하며 편집 기록을 만들지 않는다. 안쪽을 다시 드래그하면 사진·주석을 합친 선택 부분을 이동한다.
- 원래 자리는 흰색으로 채우고 도착 위치는 선택 픽셀로 덮어쓴다. 겹친 위치도 원본 패치를 먼저 복사한 뒤 처리한다. 이동 경계는 현재 이미지/자르기 범위다.
- 마우스를 놓을 때 한 번의 이동 명령을 기록한다. Ctrl+Z는 원래 자리와 덮어쓴 도착 위치를 복원한다. 이동 중 Esc는 아직 기록하지 않은 미리보기만 취소한다.
- 선택 상태 Ctrl+C는 선택 부분만 복사하며 선택 해제 후에는 전체 이미지 복사다. 저장은 전체 사진을 사용한다. 점선 테두리는 복사·저장에 포함되지 않는다.
- 도구·사진 전환·숨김·삭제 시 선택 임시 버퍼를 해제한다. 이동 중 전체 배경과 패치를 한 번 준비하고 마우스 이동마다 재생성하지 않는다.
- 이전 문서의 도구 ID와 파일 필드를 보존하고 새 이동 명령을 추가했다. 이동 기록은 재실행 시 재생한다. 기존 문서는 계속 읽으며 새 기능 편집 기록에는 0.1.13 이상이 필요하다.
- 이동 시점 이전 주석은 래스터 편집에 포함되므로 개체 선택·지우개로 이전 위치에서 다시 선택하지 않는다. 이동을 실행 취소하면 해당 주석의 이전 편집 상태가 복원된다.

## 검증

자체 숨긴 앱·합성 이미지로 역방향 영역 지정, 무편집 선택, 사진+주석 픽셀 이동, 원래 자리 흰 채움, 바깥 픽셀 보존, 겹침 이동, 선택 복사 크기, 저장/메타데이터 재읽기, Ctrl+Z, Esc, 바깥 클릭, 영면적·영이동, 잘린 이미지 경계, 버퍼 재사용·해제 및 이전 위치 주석 재선택 방지를 검사한다. 수행한 개수와 결과는 `verification/v0.1.13/pixel-selection-verification.json`을 기준으로 한다. 핵심 회귀 49개와 기본 클립보드 형식 시험 11개도 재실행한다.

기본 크기와 720×480에서 자체 컨트롤 렌더로 점선 아이콘·선택 테두리·도구 줄 배치를 확인한다. Computer Use·물리 마우스 입력·사용자 화면 캡처·시스템 클립보드 쓰기를 사용하지 않는다. 실제 사용 환경의 입력·혼합 DPI와 큰 이미지 드래그 지연은 별도 조작 검증이 남는다. 전체 알캡처·그림판 기능 동등성을 주장하지 않는다.
