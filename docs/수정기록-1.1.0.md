# LightCapture v1.1.0 영역 GIF 녹화

2026-11-04. 상단 **GIF 녹화**, 캡처 메뉴, 캡처 작업 박스의 **더 보기 → GIF 영역 녹화**를 추가했다. 기존 사각형 영역 선택으로 녹화할 화면을 지정한다. 화질과 커서 포함 여부를 고르고 시작하면 3초 뒤 녹화하며, 정지 후 움직이는 미리보기에서 저장한다. F8 또는 기존 캡처 단축키로 정지하고 Esc로 취소한다. 단축키 충돌 시 사용 가능한 키와 버튼을 안내한다.

## 화질과 파일 크기

기본은 12fps·긴 변 최대 1280px다. 선명은 15fps·1600px, 작게는 10fps·960px다. 작은 영역은 확대하지 않고 비율을 유지한다. Windows WIC의 프레임별 적응형 256색 팔레트와 LZW 인코딩을 사용하며, 정지 화면은 표시 시간을 합치고 바뀐 사각형 부분만 기록한다. 별도 프로그램이나 런타임을 설치하지 않는다. 프레임 위치·표시 시간·이전 화면 유지·반복은 [Microsoft WIC GIF 메타데이터 규약](https://learn.microsoft.com/en-us/windows/win32/wic/-wic-native-image-format-metadata-queries)에 맞춰 기록한다.

최대 2분 또는 약 80MiB에서 자동으로 마치고 미리보기를 연다. 처리 중인 프레임 때문에 파일 크기는 임계값을 조금 초과할 수 있다. 미리보기는 실제 생성한 GIF를 한 프레임씩 해독해 표시한다. 저장 취소·실패 시 미리보기를 유지하며 다른 위치에 다시 저장할 수 있다. 다시 녹화는 같은 영역에서 시작한다. GIF는 기존 사진 편집 목록에 추가하지 않는다.

## 메모리와 측정 결과

녹화할 때만 화면 수집 버퍼와 작업 스레드를 만든다. 대기열은 최대 3장이고 프레임은 임시 파일에 순서대로 기록한다. 처리보다 수집이 빠르면 표본을 건너뛰며 실제 시간 차이를 GIF에 반영한다. 취소·닫기·다시 녹화·정상 종료는 해당 임시 파일과 버퍼를 정리한다.

아래 수치는 사용자 화면을 녹화하지 않고 글자·커서와 색 변화로 만든 합성 화면을 인코딩한 결과다. 실제 영상의 복잡도나 화면 수집·축소 비용은 포함하지 않는다. 용량은 장면마다 달라진다.

| 합성 화면 | 설정·길이 | 파일 크기 | 프레임 인코딩 p95 | 프로세스 작업 집합 최대 |
| --- | --- | --- | --- | --- |
| 글자 화면에서 작은 부분 이동 | 1280×720, 12fps, 30초 | 58,244바이트(약 57KiB) | 2.961ms | 34.805MiB |
| 넓은 영역의 색이 계속 변함 | 1600×900, 15fps, 2초 | 1,565,999바이트(약 1.49MiB) | 20.695ms | 40.578MiB |

측정 시작 작업 집합은 17.027MiB, 종료 후 24.219MiB였다. 30초 합성 화면의 30프레임 간격 표본은 약 34.6~34.7MiB로 유지됐다. 이 검사는 동기식 인코더와 한 프레임씩 읽는 미리보기를 측정한 것이며, 실제 녹화에서는 화면 수집 버퍼·최대 3장 대기열의 메모리가 추가된다. 실제 화면에서의 사용량이나 입력 지연을 이 수치로 보장하지 않는다.

## 검증 범위

GIF 전용 **36개**를 통과했다. 크기·비율·확대 방지, 픽셀·색상·변경 영역 합성, 실제 재생 시간과 반복, 정지 화면 합치기, 작업 대기열 제한·표본 누락 시 시간 보존, 취소·파일 오류·임시 파일 정리, 영역 선택과 가상 화면 좌표, 3초 준비, 녹화·정지·미리보기·저장, 저장 실패 보존, 시간·크기 제한, F8·설정한 캡처 단축키·Esc의 명령 전달, 다시 녹화를 확인했다.

별도 Pillow 13.0.0으로 생성한 GIF 8개의 모든 프레임을 해독했다. 36프레임 변경 영역 시험은 매 프레임의 전체 픽셀을 독립적으로 비교했고, 총 재생 시간·이전 프레임 유지·무한 반복을 확인했다. 색 변화 시험의 평균 채널 오차는 약 6.27/255였다. 핵심 49개, 복사 형식 11개, 합성 오버레이 6개, 사각형 선택 86개, 그림판 23개, 캔버스·붙여넣기 50개와 기존 텍스트·목록 검사도 통과했다.

기본·작은 미리보기와 녹화 준비창은 자체 숨긴 컨트롤을 렌더해 확인했다. Computer Use, 실제 사용자 화면 녹화, 물리 키 입력, 외부 앱 조작, 시스템 클립보드 변경은 수행하지 않았다. 실제 모니터/DPI 변경·GPU 화면 수집·캡처 제외 동작과 다른 앱의 전역 단축키 충돌은 사용자 환경에서 확인이 필요하다. [원본 검증 자료](../verification/v1.1.0/)를 참고한다.
