# LightCapture 0.1.16 목록 포커스 테두리 정리

2026-10-26. 캡처 목록을 클릭했을 때 기존 둥근 선택 테두리 안쪽에 각진 점선 포커스 테두리를 추가로 그리던 처리를 제거했다. 키보드 포커스도 기존 둥근 외곽선에 통합한다. 썸네일 자체의 연한 테두리, 체크 배경·선택·삭제·저장·영역 이동 기능은 유지한다.

핵심 회귀 49개, 복사 형식 11개, 영역 선택 21개와 기존 목록·편집 회귀를 통과했다. 기본 크기와 720×480 자체 컨트롤 렌더에서 둥근 외곽선과 기존 썸네일 테두리를 확인했다. 검증 결과는 `verification/v0.1.16/`에 보관한다. 실제 화면·물리 입력·사용자 클립보드는 조작하지 않았다.
