# LightCapture v1.0.1 선택 영역 삭제

2026-11-04. 점선 사각형 선택 도구로 영역을 지정한 뒤 Delete 키를 누르면 해당 부분의 사진과 주석을 흰색으로 지운다. 캡처 목록과 이미지 크기는 유지하며 선택 테두리는 해제한다. Ctrl+Z 한 번으로 삭제 직전의 픽셀을 복원한다. 이동하거나 크기를 바꾼 선택 영역과 자른 이미지에서도 같은 방식으로 동작한다.

캔버스에서 사각형 선택 도구를 사용할 때 선택 영역이 없으면 Delete는 아무것도 지우지 않는다. 목록의 Delete와 상단 삭제 버튼은 기존처럼 체크한 캡처를 삭제한다. 텍스트 입력 중 Delete는 글자를 지운다.

삭제는 이동 목적지가 없는 사각형 선택 명령으로 저장한다. 삭제 기록이 포함된 이미지는 v1.0.1 이상으로 다시 열어야 한다. 기존 이동·크기 조절 기록은 계속 읽을 수 있다.

핵심 회귀 49개, 복사 형식 11개, 합성 오버레이 6개, 사각형 선택 86개, 그림판 23개, 캔버스·붙여넣기 50개 및 기존 텍스트·목록 검사를 통과했다. 새 검사 12개는 영역 안팎의 전체 픽셀, 캡처 목록 보존, 선택 해제 후 Delete, Undo·Redo, 내부 저장 기록 재읽기, 복사 PNG, 이동·크기 조절 후 삭제와 복원, 자르기 좌표를 확인한다. [검증 근거](../verification/v1.0.1/)를 참고한다.

자체 숨긴 창의 키 메시지와 합성 이미지로 검사했다. 실제 키보드 입력·사용자 화면 캡처·외부 앱 조작·시스템 클립보드 변경은 수행하지 않았다. 기존 성능·메모리 비교는 [0.1.23 보고서](성능-메모리-점검-0.1.23.md)를 참조한다.
