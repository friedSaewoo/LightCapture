# LightCapture 0.1.23 편집 반응성 개선과 정보 문구 정리

2026-10-30. 정보 보기의 다른 캡처 도구·동등성 비교 문구를 제거하고 현재 버전·Windows x64·설정된 캡처 키·그림판/저장/복사/붙여넣기 키와 종료 방법을 표시한다.

Full HD·4K 합성 편집과 100장 목록을 측정해, 반복 축소 렌더와 체크마다 전체 도구 모음을 배치하는 지연을 확인했다. 표시 배경을 최대 16MiB 크기로 캐시해 반복 드래그에서 재사용하고 원본·편집·배율·배경 변경 때 갱신한다. 트레이 숨김에는 해제한다. 체크의 리스트 갱신을 묶고 펜 굵기 패널 표시가 실제로 바뀔 때만 레이아웃을 갱신한다.

기존 회귀 검사와 표시 캐시의 픽셀·재사용·갱신·제한·해제를 확인했다. 4K 반복 드래그 p95 약 5~8ms, 편집 후 작업 집합 약 91MiB, 트레이 복귀 약 24MiB를 관측했다. 첫 캐시 생성·썸네일·복사·저장은 순간 지연이 남는다. 자세한 조건·표본 수·전용 메모리·남은 실제 조작 범위는 [성능·메모리 보고서](성능-메모리-점검-0.1.23.md)에 기록했다.

합성 벤치마크는 `--benchmark`로 재현하며 사용자 화면·클립보드·실제 앱 입력을 사용하지 않는다. 실행 중 캡처 키를 해제해 시험이 화면 캡처를 시작하지 않도록 한다. 검증 자료는 `verification/v0.1.23/`에 보관한다.
